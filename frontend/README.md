## 几个必须遵守的契约约定

1. **资源 ID 是不透明的**：只能整体比对与传递，**不得解析其结构**（见 [../docs/DATA_MODEL.md](../docs/DATA_MODEL.md) §3.3）。
2. **必须处理降级状态**：`/api/health` 会返回 `ok` / `degraded` / `down`，且 `degraded` 会指明是哪个上游坏了（如 ZSvirt 不可达）。前端必须展示这种"数据陈旧"状态，不能假装一切正常。
3. **必须处理裁剪标记**：拓扑响应中的 `truncated: true` 表示因深度或节点上限被裁剪，需要提示用户。
4. **必须区分上游故障与自身故障**：`502 UPSTREAM_UNAVAILABLE`（ZSvirt 挂了）与 `503 SERVICE_DEGRADED`（B 自己受损）语义不同。
5. **错误码是契约**：C 依赖结构化错误码分支，B 变更错误码属破坏性变更。
