# 演示视频设计 spec（交付要求 g）

> 本文是 `video-shotcraft` 共同创作流程的**产物存档**，也是交付前独立终检的
> **审查基准**。终检 Agent 必须只依赖本文与仓库产物，不得依赖聊天记录 ——
> 否则它只能靠猜"用户确认过什么"。
>
> 流程依据：`video-shotcraft` 的 `SKILL.md` 与 `references/guided-free-creation.md`。
> 本文件按它的六个阶段逐段留痕，**包括偏离与跳过**。

## 0. 一个前置判断：宣传片 ≠ 录屏

`video-shotcraft` 的产出是**电影感产品宣传片**（真实页面截图 + 2.5D 运镜 +
卡点剪辑 + SFX）。而赛题交付要求 g 的原文是：

> 「g. 真实环境演示视频：提供 3-5 分钟**录屏**，展示**部署、正常观测、故障注入、
> 跨层关联和诊断输出**的完整过程。」

官方第一轮答复第 15 条又明确：

> 「赛题的降级条款不能直接推导为『全模拟可替代最终环境演示』。赛题同时要求在
> 虚拟机中运行样例 AI 工作负载、提交真实环境演示视频……」

**结论：主体必须是真实操作的录屏，不能是宣传片。** 因此本项目的用法是**分层**：

| 层 | 内容 | 谁做 |
|---|---|---|
| 主体（约 3:40） | 终端命令 + Web 控制台的真实录屏，覆盖官方点名五环节 | 人录 |
| 包装层（约 0:50） | 片头 / 分段卡 / 常驻来源角标 / 字幕 / 片尾 | `render.mjs` 生成 |
| 纪律层 | 节奏约束（`aesthetic-rules`）+ 独立终检（`final-review`） | 流程 |

若把 Ink Press 模板成片当作交付物 g，是拿形式换掉了要求里的实质。

## 3. 视觉方向：**记录理由后跳过 styleframe**

`guided-free-creation.md` §3 允许在"用户已提供严格品牌规范 / 明确参考片 /
直接选定某模板 / 明确授权跳过"时记录理由后跳过。本次两条理由：

1. 产品自身的视觉 token 已从 `frontend/src/theme.ts` **取证**（不是猜的），
   方向唯一且明确：深色科技控制台 + 单一青蓝强调色。skill 理念 2 要求
   「视频视觉必须从产品自身生长，不能另造一套不相干的宣传片皮肤」——
   再由视频另造 2–3 个候选方向去比，反而违反它。
2. 交付物是工程/论文类录屏，不是品牌宣传片；多一轮 styleframe 对比的收益
   低于成本。

**Ink Press 模板为何未采用**：它是纸质/编辑部质感（暖调纸纹理），与产品的
深色冷调控制台（`#0F1720` + `#0E7C86`）直接冲突。skill 也明确说
「不能因为仓库里有它就固定加入」。

### 3.1 实际使用的 token（全部来自产品）

| 用途 | 值 | 来源 |
|---|---|---|
| 画面底色 | `#0F1720` | `BRAND.sidebarBg` |
| 强调色 | `#0E7C86` | `BRAND.accent` |
| 正文 | `#E6F4F5` | `BRAND.accentSoft` |
| 分隔线 | `#24313D` | 扩展（深浅介于底色与正文之间） |
| 状态 ok/warn/error/critical | `#2F855A` / `#C97B1E` / `#C0392B` / `#8E1B1B` | `STATUS` |
| 八层链路色阶 | `#334E68 → #486581 → #627D98 → #0E7C86 → #2C9A9A → #57AE9B → #D9A441 → #C97B4A` | `LAYER_COLORS` |
| 字体 | `Segoe UI` + `Microsoft YaHei`；等宽 `Cascadia Mono` / `Consolas` | 系统字体（避免 webfont 加载竞态） |

### 3.2 记录的扩展（1 处）

| 扩展 | 值 | 理由 |
|---|---|---|
| `--accent-bright` | `#3FB6C0` | 产品里最接近的 `--accent-soft`（`#E6F4F5`）与正文色是**同一个值**，只换字重的话在深色半透明字幕条上几乎看不出强调。这是 skill 允许的"克制扩展"：同色相提亮。**实测被发现**：第一版复核时 vision 仍读作 "regular white"。 |

## 4. 功能 → 镜头映射（含**偏离记录**）

⚠️ **偏离 1（重要）**：skill 的规则是「用镜头卡动效必须先读准确 demo 源码，
严禁只根据卡名含义重写」。本项目选择**纯 CSS/HTML 实现**，因此：

- 下表卡名只作**运动语法词汇表**使用，不读取、不复制任何 demo TSX；
- **代价**：放弃了那些卡里已调校好的缓动曲线与时值配比，参数由本项目自行给；
- **另一层原因**：本机网络无法取得资产库（`github.com` 与全部镜像不可达，
  仅 `api.github.com` 可达；音频/纹理等 >1 MB 文件只能拿到被墙的 `download_url`）。

| 环节 | 运动语法参考 | 画面要表达什么 |
|---|---|---|
| 片头 | `letterspace-materialize` | 产品名 + 定位 + 来源角标首次出现 |
| ① 部署 | （无包装动效） | 一条命令起服务，健康检查全绿 |
| ② 正常观测 | `odometer-digit-roll` 的**静态化**用法 | 7 节点 / 6 边，链路是上报拼出来的 |
| ③ 故障注入 | `flash-cut` | 注入瞬间一次白闪；告警聚合 |
| ③b 真实证据 | **刻意不加任何动效** | 真容器 `OOMKilled`，证据是真的 |
| ④ 跨层关联 | `label-wipe`（替代 `scanline-annotate-focus`） | 单来源看不到另一半 |
| ⑤ 诊断输出 | `stat-stagger`（替代 `value-stagger-gradient`） | 根因 / 置信 / 建议 |
| 片尾 | `logo-shrink-wordmark-lockup` | 字标收缩归位 + 技术栈 |

⚠️ **偏离 2**：④ 与 ⑤ 原本标注 `scanline-annotate-focus` 与
`value-stagger-gradient`。实现时改成"右下角信息栈 + 左下到右的标签擦入"，
理由是**包装层无法知道录屏画面里某个 UI 元素的确切坐标** ——
猜一个位置画高亮框，指错了比不指更糟。改成复述数值（不指认位置）更诚实。

## 6. 最终分镜（1920×1080 @ 30fps）

| # | 段 | 时长 | 包装层 | 录屏内容 | 字幕要点 |
|---|---|---|---|---|---|
| 0 | 片头 | 4.0s | 标题卡（字距展开，落定 hold 1.5s） | — | 产品名 + 定位 + 演示环境声明 |
| 1 | ① 部署 | 2.6 + 26.0 | 分段卡 + 字幕 | `./deploy/start.sh --demo` 启动全绿 | 演示基线三行环境变量 |
| 2 | ② 正常观测 | 2.6 + 36.0 | 分段卡 + 字幕 + 统计栈 | 拓扑页 7 节点 6 边 | 先给健康基线 |
| 3 | ③ 故障注入 | 2.6 + 66.0 | 分段卡 + 字幕×2 + **白闪一次** | 注入 → 告警列表 | 3 条告警、**2 条**同一 `diagnosisId` |
| 4 | ③b 真实证据 | 2.6 + 40.0 | 分段卡 + 字幕（**无动效**） | `docker inspect` 真实读数 | `OOMKilled=true` / `exitCode=137` / `source=probe` |
| 5 | ④ 跨层关联 | 2.6 + 40.0 | 分段卡 + 字幕 | `--cross-layer` 三份批次 | 单来源看不到另一半 |
| 6 | ⑤ 诊断输出 | 2.6 + 42.0 | 分段卡 + 字幕 + 统计栈 | 诊断详情 + 三集影响范围 | 根因 / 0.90 / 建议 |
| 7 | 片尾 | 3.0s | 结束卡（字标收缩，hold 1s） | — | 技术栈 + 可复现材料指向 |

**实测成片时长 4:32.6**（合成录屏验证），落在官方 3–5 分钟区间内。
真实录制后需重跑 `node compose.mjs` 复核该数字。

### 节奏自检（对照 `references/aesthetic-rules.md`）

| 约束 | 本片 |
|---|---|
| 每镜只讲一个动效 | ✅ 8 段 8 种语法 |
| 同一种动效全片只当一次主角 | ✅ ⑤ 号镜由 `odometer` 改为 `stat-stagger`，避免与 ② 重复 |
| 品牌字标落定 hold ≥ 1s | ✅ 片头 1.5s、片尾 1s |
| 批量动效收尾留 ≥0.5s 静止 | ✅ 统计栈 0.9s 入场后静止保持 |
| 全片整画面冲击 ≤3 处 | ✅ 仅 ③ 号镜一次白闪 |
| 确定性渲染（禁 `Date.now` / 随机） | ✅ 全部动画写成 `t` 的纯函数，逐帧可复现 |

### 时长语义（**踩过的坑，务必遵守**）

`timeline.json` 里 overlay 有**两个**时间概念，不可混用：

- `from` / `to`：图层在录屏时间轴上的**可见区间**
- `animSeconds`：**入场动画**长度，之后静止保持

第一版只有一个 `seconds` 字段承担两种含义，结果统计栈（本意动画 0.9 秒）
在成片里只出现 0.9 秒就消失 —— 而渲染日志、合成日志、时长自检**全是绿的**。
一个字段两种含义，出错是迟早的事。

## 7. 数据合规口径

| 项 | 结论 |
|---|---|
| 演示数据性质 | 全部合成（`demo-agent` / `demo-*` / `SIM-A10-0001`） |
| 客户/个人信息 | 无 |
| 凭据 | 无。录制前须确认画面中不出现 `backend/.env` |
| 需在画面标注 | GPU 指标 `simulated`；平台层"代为上报"；容器事件 `probe`（真实） |
| 标注方式 | 常驻右上角三行角标（覆盖每一段，含分段卡） |

官方答复第 13 条还要求：「若因果链中的某个关键指标是模拟值，诊断结论也应
明确其为模拟验证」。本片在涉及 GPU 数据的段（②③④⑤）角标均在画面内，
字幕也明确写出证据来源。
